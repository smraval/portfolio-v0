Overview

At Arycs Technologies, I worked on the software behind a hardware testing platform, from its underlying Linux environment to the interfaces engineers use to control it. My role spanned system development, performance evaluation, and interface design, giving me ownership across different parts of the product.

Hardware UI

Designing for something you can touch

An interface for a hardware product is different from one that lives only on a screen. It stands in for something physical that can be slow to respond, or in a state the user cannot see. Working with such constraints made me consider how interfaces communicate system behavior and provide feedback to help users better understand what is happening beyond the screen.
